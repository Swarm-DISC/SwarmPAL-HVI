# Example notebooks for SwarmPAL-HVI

## Run

Clone the repository and change directory to `notebooks`:
```console
git clone https://github.com/Swarm-DISC/SwarmPAL-HVI/
cd SwarmPAL-HVI/notebooks
```

Setup a virtual environment and install SwarmPAL-HVI and Jupyter:
```console
uv venv
. .venv/bin/activate
uv pip install ..
uv pip install jupyter jupytext matplotlib pandas geopandas netcdf4
```

Run Jupyter:
```console
jupyter notebook
```
Open the example notebook by right clicking on it and 'Open With' -> 'Notebook'.
